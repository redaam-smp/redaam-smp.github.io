# RE:DAAM SMP

[홈페이지 바로 보기](https://redaam-smp.github.io/)

밝은 아이보리와 큰 타이포그래피를 사용한 모바일 중심 SMP 홈페이지입니다.

- 부위별 안내 필터, 가격 안내, FAQ, 주소 복사, 카카오 상담 연결
- 원장 제공 프로필·시술 전후·작업·매장 사진 반영
- 게시 사진은 사용자가 제공한 RE:DAAM SMP 자료입니다. 전후 비교는 원본 이미지를 유지합니다.
- 연락처 충돌로 전화 버튼은 제외했습니다. 상담은 제공된 카카오채널로 연결합니다.
- 검색 노출은 noindex로 설정했습니다.
